# Stash

Stash is an intelligent agent that helps users save and organize web links. It features smart tagging and summarization using Gemini.

## Features
- **Smart Stashing**: Automatically scrapes, summarizes, and tags links.
- **User Authentication**: Sign up and sign in to save your personal stash.
- **Search**: Full-text search over summaries, tags, and URLs.
