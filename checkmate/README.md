# Checkmate

Checkmate is an intelligent checklist assistant agent built with Google ADK. It helps users organize their lives by turning high-level lists and needs into granular, actionable tasks.

## Features
- **Intelligent Breakdown**: Automatically decomposes tasks into subtasks.
- **Checklist Management**: Create, update, and manage checklists.
